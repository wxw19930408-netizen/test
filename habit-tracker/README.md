# 小习惯 · 每日打卡

一个简单的本地习惯打卡网页。

## 使用

双击 `index.html`，用浏览器打开即可。

- 在输入框里添加想坚持的习惯，回车或点「添加」
- 每天完成一项，点一下前面的方框打勾，会记录当次打卡时间
- 顶部会显示今天已完成几项，以及完成比例
- 连续两天以上打卡的习惯会显示连续天数
- 已完成的习惯会显示当天最近一次打卡时间；重复打卡会追加新的历史记录
- 页面底部的「打卡历史」按日期保存每一次打卡，可展开查看过去日期
- 删除习惯后，几秒内可以点「撤销」

## 数据

打卡数据保存在当前浏览器的 `localStorage` 中，不会上传到任何地方。
日期切换后会自动开始新的一天，历史打卡会保留，可在页面下方查看并用于计算连续天数。

旧版数据首次打开时会自动升级，并在 `habit-tracker-v1-backup` 中保留一份原始备份。
旧记录没有保存时间，会显示为「未记录时间」。

清除浏览器网站数据会同时清空打卡记录，需要的话可以定期备份。
